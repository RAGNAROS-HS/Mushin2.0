Will write about it once I'm done.

In the meantime, the shape of it: Mushin is the source for the personal website and portfolio at hugokatzer.tech. It uses Hugo for static site generation, chosen for its speed and markdown-native approach — which lines up neatly with GitHub README files, so writing can be cross-posted rather than rewritten.

Sections

  • Home — brief introduction and profile
  • Projects — portfolio of work and research (MSc AI projects, theses)
  • Devlog — development logs and updates
  • About me — background information

Local Development

Requirements: Hugo installed.

# clone
git clone https://github.com/RAGNAROS-HS/Mushin.git && cd Mushin

# run locally, available at localhost:1313
hugo server -D

# build production output into public/
hugo

# create content
hugo new content/devlog/my-new-post.md

Deployment

The site runs on a Cloudpanel VPS with automated SFTP deployment via GitHub Actions on every push to main.

Mushin 2.0 — the site you are reading now — is a hand-rolled, build-step-free rework of the same material in plain HTML, CSS and one file of vanilla JavaScript. No Hugo, no theme, no generator.
